# Security policy

## Supported versions

We support only the latest version. This is the latest commit on `main` and the latest release. We do not fix earlier versions.

## Report a vulnerability

WARNING: Do not report a vulnerability in a public issue, a pull request or a discussion. A public report tells attackers about the problem before a fix exists.

Report each vulnerability privately through GitHub Security Advisories:

1. Go to the repository on GitHub.
2. Open the **Security** tab.
3. Click **Report a vulnerability**.
4. Write the affected version and the steps that cause the problem.
5. Write the effect that an attacker can get.
6. Submit the report.

Use this link to open the private report form:
<https://github.com/orlavid/app-template-web/security/advisories/new>.

## What we do

- We reply to your report within 3 working days.
- Within 30 days, we release a fix or we send you a plan with a date for the fix.
- We tell you when we publish the fix.
- We give you credit in the advisory, if you agree.
